1. 画面デザイン

コードレビュー一覧モックアップを開く

本システムに登録済みのプルリクエスト（以下 PR）のレビュー状況をリポジトリ単位で一覧表示する。ユーザーはこの画面を起点に、レビュー依頼の登録、レビュー結果の確認、対応が完了したレビューのクローズを行う。本書は日本語画面を対象とする。

前提GitHub連携設定（SCR-04）でPersonal Access Token（以下 PAT）が有効に設定済みであること。未設定の場合は一覧を表示せず設定への導線を提示する（6. 画面状態参照）。

共通ヘッダー、サイドナビゲーション、サイドバー開閉およびパンくずは共通画面項目に従う。以下は本画面固有の項目を示す。

3. 入力項目・操作項目の振る舞い

3.1 入力チェック

ID対象チェック契機チェック内容不正時の振る舞い
LST-V01PAT設定状態初期表示、一覧再取得時GitHubアクセスに必要な認証情報が設定済みかつ有効であること。一覧を非表示にし、LST-05とLST-06を表示する。PAT値は画面、URL、ログへ出力しない。
LST-V02リポジトリ絞り込み（LST-07）選択変更時、再表示時取得済みの選択肢からの単一選択であり、「すべて」または参照可能なリポジトリであること。「すべて」に戻し、一覧を再取得する。
LST-V03レビュー状態絞り込み（LST-08）選択変更時、再表示時定義済み選択肢からの単一選択であること。「すべて」に戻し、一覧を再表示する。
LST-V04検索（LST-09）入力時任意の文字列を許容する。前後空白を除去し、大文字・小文字を区別しない。文字種・文字数による入力拒否は行わない。入力は受け付け、正規化した文字列で照合する。
LST-V05レビューID結果画面遷移時、クローズ時表示時に取得した一覧に存在し、利用者が参照可能なレビューであること。操作を中止して一覧を再取得し、対象が更新または削除された旨を通知する。

3.2 操作

ID操作前提条件正常時の振る舞い異常時の振る舞い
LST-A01レビュー依頼を登録するPAT設定済みLST-03を選択するとSCR-02へ遷移する。遷移できない場合は現在画面を維持する。
LST-A02リポジトリで絞り込むPAT設定済み選択変更で即時に一覧を再描画し、選択リポジトリ（org/repo）に完全一致するレビューのみ表示する。「すべて」は全リポジトリを対象とする。不正選択時はLST-V02に従う。
LST-A03レビュー状態で絞り込むPAT設定済み選択変更で即時に一覧を再描画し、選択状態に一致するレビューのみ表示する。他の絞り込み条件とAND結合する。不正選択時はLST-V03に従う。
LST-A04キーワードで検索するPAT設定済み入力のたびに即時に再描画し、PR番号・タイトル・ブランチ名を対象に部分一致で照合する。再描画後も入力欄のフォーカスとカーソル位置を維持する。他の絞り込み条件とAND結合する。—
LST-A05絞り込み条件を保持するなしリポジトリ・レビュー状態・検索キーワードを利用者単位で保存し、再表示時に復元する。保存済み値が選択肢に存在しない場合は当該条件を「すべて」に戻す。
LST-A06グループを展開／折りたたむ該当行あり選択で当該リポジトリの表示／非表示を切り替える。折りたたみ時は列ヘッダーと明細行を非表示にし、見出しと件数のみ表示する。状態はリポジトリ単位で保存し、絞り込みや再表示をまたいで維持する。状態を保存できない場合も当該表示中は切替を有効とする。
LST-A07レビュー結果を開く対象レビューを参照可能LST-12を選択するとSCR-03へ遷移し、レビューIDを引き渡す。結果画面でのコメント対応（対応済み／誤検知／未対応へ戻す）は、本画面のレビュー状態およびコメント件数へ反映する。対象が参照不可の場合はLST-V05に従う。
LST-A08レビューをクローズする対象レビューへの対応が完了している（下記表示条件を満たす）対応完了済みレビューを管理対象から終了し、一覧から除外する（GitHub上のPRをクローズする操作ではない）。クリック時に確認を求め、同意後にクローズ済みとして記録し、一覧から即時除外する。リポジトリグループの件数を更新し、該当行が0件になったグループは非表示にする。クローズ状態は保存し再表示時も維持する。操作直後に取り消し手段を提示する。対象が既に更新・削除済みの場合はLST-V05に従う。
LST-A09登録完了通知を閉じるLST-04表示中通知を非表示にする。—
LST-A10設定画面を開くPAT未設定または無効LST-06を選択するとSCR-04へ遷移する。遷移できない場合は現在画面を維持する。

クローズの表示条件（LST-18／LST-A08）：レビューへの対応が完了しており一覧で追跡する必要がない行にのみ「クローズ」を表示する。具体的には、レビュー状態が「完了」（レビュー済みかつ未解決コメントなし）である行、またはPRステータスが Closed もしくは Merged の行を対象とする。

4. レビュー状態の判定

レビュー状態色判定条件
未実施グレー #E0E0E0レビュー解析が未開始である。
レビュー中青 #D0E2FFレビュー解析が処理中である。
対応待ち紫 #E8DAFFレビュー済みで、未解決コメントが1件以上存在する。
完了緑 #A7F0BAレビュー済みで、未解決コメントが存在しない（全コメントが対応済みまたは誤検知）。
エラー赤 #FFD7D9レビュー処理でエラーが発生した。再試行要求の受付後は「未実施」へ戻る。

コメント列（LST-16）は検出コメントの件数を表示する。未解決件数はレビュー状態の判定に用いる。PRステータス（LST-15）はレビュー状態とは独立に、GitHub上のPR状態（Open／Closed／Merged）を表示する。
