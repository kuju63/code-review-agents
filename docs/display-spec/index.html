1. 文書の目的

PR Review Agentの静的UIモックアップを基に、利用者から見える画面項目、入力条件、操作、画面遷移および状態変化を定義する。本書は日本語画面を対象とする。

設計上の位置づけ モックアップは画面確認用の静的実装であり、本書には本番実装で必要となる入力チェックを追加している。モックアップと本書が異なる場合、入力チェックについては本書を優先する。

2. 画面一覧

  • SCR-01 コードレビュー一覧登録済みPRの状態確認、絞り込み、結果表示、クローズ
  • SCR-02 レビュー依頼登録Organization、リポジトリ、PRの選択とレビュー依頼送信
  • SCR-03 レビュー結果確認処理状態、変更差分、レビューコメントの確認と対応
  • SCR-04 GitHub連携設定GitHub URLおよびPersonal Access Tokenの登録

3. 共通画面項目

ID項目名種別表示内容操作・振る舞い
COM-01ブランドリンクPR Review Agent選択するとSCR-01へ遷移する。
COM-02言語切替ボタンJA / ENモックアップでは選択言語を保存して再表示する。本外部設計書の対象言語は日本語のみとする。

COM-05サイドバー表示切替ボタン折りたたむ／展開アイコンサイドバーのラベル表示を切り替える。状態はブラウザ単位で保持する。
COM-06パンくずリンク／テキスト現在画面までの階層リンク部分を選択すると対応画面へ遷移する。

4. 共通振る舞い

ID条件・操作振る舞い
CB-01画面表示処理中は同一操作の重複実行を防ぐ。取得失敗時は原因を利用者向けに表示し、再試行または戻り先を提示する。
CB-02入力エラー対象項目をエラー表示し、項目直下に日本語のエラーメッセージを表示する。最初のエラー項目へフォーカスし、保存または送信を行わない。
CB-03外部リンクGitHub上のブランチおよびコミットは新しいタブで開き、元画面を維持する。
CB-04PAT未設定SCR-01およびSCR-02の主要機能を表示せず、未設定通知とSCR-04への導線を表示する。
CB-05状態保持言語、サイドバー状態、画面表示設定等はブラウザ単位で保持できる。認証情報はブラウザの平文ストレージへ保存しない。
